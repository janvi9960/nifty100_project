# Nifty 100 Analytics Dashboard

## Project Overview

This project provides a financial analytics platform for Nifty 100 companies using Python, SQLite, Streamlit, and Plotly.

The project covers:

- Data ingestion and ETL
- Financial statement analysis
- Financial ratio calculation
- Capital allocation analysis
- Interactive Streamlit dashboard
- Company screening
- Peer comparison
- Trend analysis
- Sector analysis
- Valuation analysis
- Annual report access

## Technologies Used

- Python
- Pandas
- NumPy
- SQLite
- Streamlit
- Plotly
- Excel
- Git

## Database

The main database is:

`data/nifty100.db`

The database contains financial and market data for 92 Nifty 100 companies.
